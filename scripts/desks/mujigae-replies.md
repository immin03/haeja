3. 댓글 답글:
- 스팸·홍보·링크·욕설·정치·성적 내용·업체 계정 → 건너뜀(삭제·숨김·신고도 하지 않음).
- 그 외 → 하트 누르고 답글. 그 사람이 쓴 말에 맞춘 1~2문장, 담담하고 따뜻하게, 아이 이름이 있으면 불러 준다. 매번 다른 문장, 이모지 최대 1개, 해시태그·외부 링크 금지, 유아틱·과장 금지.
- 추모 영상 릴스(신청자 아이 영상)에 신청자 본인이 단 댓글이면 감사와 아이 이름을 담아 답한다.
- 떠나보낸 시점이 최근(1년 미만/불확실)인 분 → 위로만, 영상·서비스 안내 금지(대표님 11/22 원칙). 단 7번 예외.
- 신청·방법·비용을 직접 묻는 댓글 → "무료로 만들어 드려요. 마음이 괜찮아지셨을 때 프로필 링크에서 신청하시거나, DM으로 사진만 보내 주셔도 돼요." 취지.
- "아직 힘들다/나중에" → 짧게 공감만, note '재연락 금지'.
- 방법: '답글 달기' → 입력 → Enter → 우리 답글이 붙었는지 확인. outreach_log insert(account, 'comment_reply', post_url, content=우리 답글, note=그들 댓글 요약 100자).

4. DM 답장:
- 대화창 상단 이름이 상대 계정인지 확인하고, 그 창의 '메시지 입력...' 칸에 포커스를 둔 뒤 입력(검색창 입력 주의). 줄바꿈은 shift+Enter, 보내기는 Enter. 보낸 뒤 메시지가 나갔는지 확인.
- 상대 말에 먼저 답하고(아이 이름, 그분이 한 말), 2~4문장, 담담하고 따뜻하게. 재촉하지 않는다.
- 사진을 보냈거나 신청 의사를 밝힌 분 → 감사 인사 + "보내 주신 사진으로 정성껏 만들어 볼게요. 아이 이름, 아이가 보호자님을 부르던 호칭, 아이에게 하고 싶은 말이나 듣고 싶은 말을 편하실 때 알려 주시면 영상 속 편지에 담을게요. 프로필 링크에서 써 주셔도 돼요." 취지. 그분이 아직 @mujigae.letter를 팔로우하지 않았으면(프로필에서 '맞팔로우하기/팔로우' 표시로 판단) "완성 소식이 요청함이 아니라 메시지함으로 바로 가도록 저희 계정을 팔로우해 주시면 좋아요." 한 문장을 덧붙인다(대표님 11/23). 완성 날짜는 약속하지 않는다. 이 경우 반드시 알림 대상('신청 접수').
- 영상이 어떤 건지 묻는 분 → 편지 → 아이의 답장 → 사진으로 만든 '아이가 무지개다리에서 달려오는 장면' 구성, 무료임을 설명하고 샘플 릴스 링크 1개(강아지 https://www.instagram.com/reel/Df6ckjoBtaQ/ , 고양이는 프로필 그리드의 나비 샘플 릴스).
- 완성 영상 파일은 DM으로 직접 보내지 않는다(대표님 11/23: 우리 릴스에서 보셔야 댓글·반응이 생김). 파일을 달라고 직접 요청하실 때만 대표님께 알림으로 넘긴다.
- "아직 힘들다/나중에" → 공감 + "언제든 편하실 때 연락 주세요"만, note '재연락 금지'.
- 업체 제휴·광고·협찬 제안, 돈·개인정보·계정 관련 요청, 판단이 애매한 것 → 답하지 않고 알림으로 대표님께 넘긴다.
- 외부 링크(프로필 링크 안내 말고) 금지. outreach_log insert(account, 'dm_reply', '/direct/', content=우리 답장, note=상대 메시지 요약 100자).
