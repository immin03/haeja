# 제1 원칙 (대표님 지시) — 모든 제작·게시 작업이 가장 먼저 따른다

운영자(최민우) 2026-10-29: "게시하는 방법이 계속 바뀌잖아. 이게 맞는지 나도 계속 검수를 해야 될 거 아니야. 검수할 수 있는 창을 관리자 페이지에 만들어 주고, 아닐 때 내가 바로 피드백해서 업데이트할 수 있는 칸도 만들어 줘. 그게 무조건 우리의 제1 원칙이 되는 거야. 무조건 다 같이 따라야 되는 거고."

- 원본: Supabase docs collection 'agent', id 'owner-rules' (관리자 → 개요 → 운영 기준에서 대표님이 적음). 이 파일은 그 사본이다.
- 순서: **이 파일(=owner-rules) > 작업 지시문 > 각 README·FORMAT > 벤치마킹·성과 규칙**. 충돌하면 무조건 이 파일을 따른다.
- 채널이 '전체'인 원칙은 모든 작업에, 특정 채널 원칙은 그 채널을 만드는 모든 작업(제작·검수·업로드·벤치마킹·성과 개선)에 적용된다.
- 이 파일은 예약 작업 '제1 원칙 반영'이 관리한다. 직접 고치지 말고 관리자 화면에 적는다.
