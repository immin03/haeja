# 제1 원칙 (대표님 지시) — 모든 제작·게시 작업이 가장 먼저 따른다

운영자(최민우) 2026-10-29: "게시하는 방법이 계속 바뀌잖아. 이게 맞는지 나도 계속 검수를 해야 될 거 아니야. 검수할 수 있는 창을 관리자 페이지에 만들어 주고, 아닐 때 내가 바로 피드백해서 업데이트할 수 있는 칸도 만들어 줘. 그게 무조건 우리의 제1 원칙이 되는 거야. 무조건 다 같이 따라야 되는 거고."

- 원본: Supabase docs collection 'agent', id 'owner-rules' (관리자 → 개요 → 운영 기준에서 대표님이 적음). 이 파일은 그 사본이다.
- 순서: **이 파일(=owner-rules) > 작업 지시문 > 각 README·FORMAT > 벤치마킹·성과 규칙**. 충돌하면 무조건 이 파일을 따른다.
- 채널이 '전체'인 원칙은 모든 작업에, 특정 채널 원칙은 그 채널을 만드는 모든 작업(제작·검수·업로드·벤치마킹·성과 개선)에 적용된다.
- 이 파일은 예약 작업 '제1 원칙 반영'이 관리한다. 직접 고치지 말고 관리자 화면에 적는다.

## 적용 중

1. [전체 · 10/29] 관리자 → 운영 기준에 적는 피드백이 우리의 제1 원칙이다. 모든 제작·게시 작업은 다른 어떤 규칙보다 이것을 먼저, 무조건 따른다.
2. [카드뉴스 · 10/29] 카드뉴스는 하루 2~3편 꾸준히 올린다: 08:30 저장형 · 15:30 이슈형(실적 정리형/화제형) · 19:30 화제형, 하루 최소 2편 ("카드뉴스는 하루에 2~3개는 꾸준하게 올라오게").
3. [카드뉴스 · 10/29] 우리 톤의 화제성 카드도 올리고, 모든 카드의 마지막 장과 캡션 끝에 "현명한 투자를 하고 싶다면 팔로우, 유익했다면 저장하고 소중한 사람에게 공유" 유도를 넣는다.
4. [전체 · 10/29] 훅 문구 기준 scripts/HOOKS.md(22가지 유형)를 "문제없는 범위에서 최대한" 쓴다 — 쇼츠·릴스는 첫 3초, 롱폼은 썸네일 문구와 첫 5초, 카드뉴스는 표지, 블로그는 제목에 훅을 넣는다. 조건: 2줄·한 줄 14자 안팎, 구체 숫자 1개 이상 + 대상(회사·인물 또는 "당신"), 던진 질문은 콘텐츠 안에서 반드시 답한다, 확인된 숫자만, '충격·무조건·거짓·폭락 확정·지금 안 사면' 같은 단정·공포·매수 유도어 금지, 기획안에 유형 번호(hook_type) 기록, 같은 날 같은 채널에서 같은 유형 반복 금지, 롱폼 썸네일 3안은 서로 다른 유형.
5. [유튜브 쇼츠·인스타 릴스 · 10/29] 쇼츠와 릴스는 같은 스타일로 통합한다("릴스 스타일과 동일하게") — 화면은 대표님이 좋다고 한 테슬라·스페이스X 릴스의 팝업 노트(world "popup")로만 만들고, 잉크 노트(world "ink", 손글씨로 말을 받아쓰고 펜이 처음부터 끝까지 쓰는 방식)는 쓰지 않는다("쇼츠는 좀 어수선하고"). 말을 그대로 받아쓰지 않고 핵심 명사·숫자만 깔끔하게 정렬된 인쇄 글씨로, 펜은 장면마다 핵심 한 곳만, 색은 상승 초록·하락 빨강 외엔 줄이고 크기·굵기로 구분, 장면 하나에 1~2문장, 관련 실물 사진 장면을 넣는다. 썸네일은 지금 기준 그대로. 기준 문서: scripts/reels/README.md '★ 쇼츠 = 릴스 스타일'. 아직 안 올라간 잉크 노트 쇼츠·릴스는 대사는 그대로 두고 화면만 팝업 노트로 바꿔 다시 렌더한다.
6. [전체 · 10/29] 화면 글씨에서 흐름·변화(예: 1936년 → 1988년)는 '>'(괄호·부등호)가 아니라 진짜 화살표 '→'로 쓴다. '>'는 '더 크다'로 읽힌다. 글꼴이 →를 >처럼 그리면 렌더러가 화살표(몸통+머리)를 직접 그린다(inkworld.ttext).
7. [유튜브 롱폼 · 10/29] 롱폼 노트 화면 글씨는 정렬을 딱딱 맞춘다: 좌측·가운데·우측 정렬 기준선을 하나로 모으고, 같은 줄 글씨는 같은 높이, 식(= ≈ →) 뒤 값은 떠 있지 않게 바로 옆에, 덩어리는 종이 세로 가운데로(sketch.grid·vcenter가 자동 적용). 원고를 쓸 때도 x는 140 / 사진 옆 열 / 1000 처럼 몇 개 기준선만 쓴다.
