# 밸류노트 유튜브 롱폼 메인 포맷 (v1, 2026-10-21 첫 편 SK하이닉스 기준)

롱폼은 모두 이 틀로 만든다. 새 편은 `specs/<id>.json` 하나만 쓰면 되고, 숫자·앱 화면·영상·썸네일·설명란은 자동으로 만들어진다.

## 1. 편성
| 요일 | 시리즈 | 원고 재료 |
|---|---|---|
| 월 19:00 | 이번 주 꼭 알아야 할 경제 뉴스 5 | 네이버 뉴스·검색어 트렌드, 주간 칼럼, 경제 레이더 |
| 수 19:00 | 워렌 버핏이라면 지금 이 주식을 살까 (간판) | 기업 분석 블로그·정리본, 밸류노트 데이터 |
| 금 19:00 | 거장의 투자 | 거장 시리즈 블로그, 과거 시점 재계산 |
- 반응이 좋으면 주 5회로 늘린다(화·목 추가). 큰 이슈는 긴급편으로 한 칸을 바꾼다.
- 첫 편은 10/21(수) 21:00.

## 2. 원고 구조 (8~10분)
1. **0:00–0:40 훅**: 결론을 먼저 말한다(How Money Works). "끝까지 보면 무엇을 알게 되는지"를 한 문장으로 예고한다(열린 고리).
2. **결론 카드**: 적정 주가와 지금 주가를 나란히 보여 준다.
3. **이 회사는 어떤 회사인가**: 처음 보는 사람을 기준으로 설명한다.
4. **지금 얼마나 버나**: 막대 차트로 보여 준다.
5. **밸류노트 소개 (1분 안팎, 광고처럼 보이지 않게)**
   - 앱 화면(렌더 직전 캡처)을 보여 주고 점수·재무·가격 점수를 읽는다.
   - 같은 기준으로 **과거 시점**을 다시 계산한다(그때의 점수, 그때 1억 → 지금). 미리 정한 후보 중 하나였다는 점과 늘 그렇지는 않다는 점을 꼭 밝힌다.
6. **계산 방법**: 그레이엄·워렌 버핏의 방식을 설명한다.
7. **지금 주가는 무엇을 믿고 있나**: 거꾸로 계산한 표를 보여 준다.
8. **원인 분석**: 헤드라인 뒤에서 돈이 어떻게 움직였는지 보여 준다(Wall Street Millennial).
9. **반전·경쟁·리스크**: 갈등 → 반전 → 결과 순서로 이야기를 고조시킨다(MagnatesMedia).
10. **과거 사이클**: 비슷한 일이 어떻게 끝났는지 보여 준다.
11. **앞으로 볼 숫자 5개**
12. **이 분석이 틀릴 수 있는 경우**
13. **정리 5줄**
14. **다음 편 예고와 구독 안내**

## 3. 문장 규칙
- 모든 문장에 주어를 쓴다("SK하이닉스는 …").
- 사람 이름은 "워렌 버핏", "찰리 멍거", "벤저민 그레이엄"으로 쓴다.
- 용어는 하나로 통일한다: 적정 주가, 저평가/고평가, 밸류노트 점수, 재무 점수, 가격 점수.
- "밸류노트가 평가했다"라고 쓰지 않는다. "워렌 버핏·그레이엄의 방식으로 계산한"이라고 쓴다.
- 매수·매도를 권하는 표현과 공포를 자극하는 표현은 쓰지 않는다.
- 과거 사례는 반드시 그 시점의 점수로 말한다(시점 맞추기).
- 처음 나오는 용어(PER, 정상 이익, HBM4 등)는 그 자리에서 한 줄로 풀어 준다.

## 4. 숫자 규칙 (며칠 뒤 올려도 틀리지 않게)
- 원고에는 현재가·적정 주가·점수를 직접 적지 않는다. `{px}` `{iv}` `{mult}` `{score}` `{px_label}` `{bt_won}` 같은 빈칸으로 둔다.
- 빈칸은 `data.mjs`가 렌더 직전 최신 데이터로 채운다. 계산은 앱과 같은 공식(scoring.js + vnscore.mjs)을 쓴다.
- 화면과 설명란에 "○월 ○일 종가 기준"을 표시한다.
- 고정 사실(과거 실적, 점유율 등)은 날짜와 출처를 화면 아래에 적는다.
- 그 회사의 일정(실적 발표 등)은 `events`에 넣는다. 일정이 지나면 원고 수정 요청이 자동으로 걸린다.
- 다음 중 하나에 해당하면 자동으로 다시 만든다: 렌더 후 24시간 경과, 주가 5% 넘게 변동. 승인 버튼을 누를 때도 한 번 더 확인한다.

## 5. 화면 종류 (`v.type`)
| 종류 | 쓰임 |
|---|---|
| `broll` | 무료 실사 영상 위 큰 제목 (Mixkit) |
| `split` | 두 숫자 비교 (숫자가 올라가며 세어짐) |
| `bars` | 세로·가로 막대 |
| `table` | 표 (강조 행) |
| `list` | 차례로 나타나는 목록 |
| `phone` | 앱 화면 (`img: "capture:<종목코드>"`) |
| `end` | 구독 안내 |

공통 요소:
- 위쪽 진행 막대, 로고, 현재 챕터 표시
- 자막 속 숫자는 금색
- 화면 아래에 출처와 데이터 기준일
- 효과음은 쓰지 않고, 장면 사이는 0.4초 페이드
- 성우는 타입캐스트 '성호'

## 6. 검수 순서
1. 원고를 쓴 뒤 **별도 검수 에이전트**가 사실, 시점, 문장 규칙, 처음 보는 사람 기준을 확인한다.
2. 렌더 후 25초 간격 장면 시트를 만들어 글자 겹침, 숫자, 앱 화면을 확인한다.
3. 관리자 **유튜브 검수** 탭에서 운영자가 승인한다.
   - 심사 전: 다운로드 후 직접 업로드
   - 심사 후: 예약 자동 업로드
