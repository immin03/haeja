# 롱폼 검수 체크리스트 (운영자 지시 모음, 2026-10-21~22)

렌더가 끝나면 아래를 하나씩 확인한다. 자동 확인은 `python3 qa.py <video.mp4> <meta.json>`.

## 화면
- [ ] 같은 배경 화면이 2~3초 넘게 그대로 머물지 않는다 (끝 화면 제외). 자동: qa.py static
- [ ] 장면 내용에 맞는 사진·영상이 나온다 (예: 일본 상사 → 도쿄·항구, 창신메모리 → 중국 도시, 2018년 호황의 끝 → 폭풍·신문)
- [ ] 같은 사진·영상이 영상 안에서 두 번 나오지 않는다. 릴스에서 닳도록 쓴 공용 영상(지폐 얼굴, 회로기판, 로봇 팔, 서버 복도)을 쓰지 않는다. 자동: qa.py media
- [ ] 밸류노트 앱 장면: 여러 화면(회사 상세 스크롤 · 기업 목록 · 저평가 · 브리핑 · 포트폴리오)이 번갈아 나오고, 각 화면은 스크롤된다. 같은 화면 반복 없음
- [ ] 숫자 카드는 숫자만 크게 (문장을 화면에 다시 쓰지 않는다)

- [ ] 로고·오른쪽 위 장 제목·아래 자막이 표·그림·카드를 가리지 않는다 (--stills로 장면별 확인)
- [ ] 카드·칩 안 글자가 칸 밖으로 삐져나오지 않는다
- [ ] 장 제목은 명사형 (예: '워렌 버핏식 가치 평가')

## 자막
- [ ] 한 문장의 자막은 한 번만 나온다 (껐다 켜졌다, 두 번 반복 없음)
- [ ] 두 줄이 넘는 문장은 잘리지 않고 말하는 속도에 맞춰 두 줄씩 넘어간다
- [ ] 숫자는 금색

## 소리
- [ ] 목소리: 성호(차분한 남성). 원음보다 24% 빠르게(2026-10-22 상향), 톤 살짝 위. 자동: qa.py audio.syll_per_sec (6.5~8 목표)
- [ ] 발음: 4.4배(사 점 사 배), 1~2년, HBM4, Y1, 12개(열두 개), PER(피이알) 등. 자동: qa.py pron (점수 낮은 줄은 직접 듣기)
- [ ] 배경음악: 잔잔하게, 말할 때 자동으로 작아진다. 말소리를 가리지 않는다. 자동: qa.py audio (음악만 구간이 말소리보다 15dB 이상 작게)

## 내용·말투
- [ ] 전문 용어 나열보다 이야기체. "~입니다"만 반복하지 않는다. 회사 이름을 문장마다 반복하지 않는다
- [ ] 핵심 주제는 회사(밸류노트가 아니다). 밸류노트 소개는 짧고 자연스럽게: 버핏·멍거·그레이엄·버크셔의 기준과 패턴을 분석한 알고리즘, 앱 화면, 과거 사례(일본 종합상사, 같은 회사의 과거 점수)
- [ ] 광고처럼 들리지 않는다 (마무리 한 줄 + 설명란 링크)
- [ ] 숫자는 렌더 시점 최신값, 기준일 표기. 과거 사례는 '가장 크게 오른 사례'라는 한계도 말한다
- [ ] 투자 권유 아님 문구, 출처

- [ ] 구독 안내: 요일 약속 없이 정중하게 (구독·좋아요·알림 설정, 더 좋은 분석으로 보답)

## 게시
- [ ] 썸네일: 관련 사진 한 장 + 굵은 두 줄(흰 줄: 회사·주제, 노란 큰 줄: 숫자 질문 예 "29만 원?"), 그 밖의 글자 없음
- [ ] 검수 탭에 올라왔는지, 게시 예약 시간, 제목·설명·태그·고정 댓글
