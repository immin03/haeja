# 황제의 일기 장면 라이브러리 운영 규칙 (2026-11-05 대표 확정)

대표 지시 요약: "재활용할 수 있는 장면 위주로 미리 만들어 두고, 새 에피소드를 할 때 거기에 맞춰 몇 개만 추가한다. 이 방향으로 갈 수 있게 규칙을 유지하자."
쇼츠·롱폼을 만드는 모든 세션과 예약 작업은 새 그림·영상을 만들기 전에 이 문서를 먼저 따른다.

## 1. 기본 원칙
- 먼저 라이브러리에서 찾고, 없을 때만 새로 만든다.
- 새로 만드는 장면도 가능하면 범용으로 만들어 라이브러리에 넣는다(그 편에만 쓰는 인물·사건 장면은 예외).
- 기준 목록: `scripts/side/emperor/CLIPS.json`(쇼츠·롱폼 공용 클립 목록), `scripts/side/ed_long/library.py`(LIB) + `library_u.py`(범용 U).

## 2. 영상 모델
- 기본은 wan 3.0 (5초 약 0.10달러).
- seedance 2.5(5초 약 0.75달러)는 wan 결과가 얼굴·손 깨짐 등으로 못 쓸 때 그 장면 하나만 `python3 library.py gen <n> hq` 로 다시 만든다.
- kling 은 쓰지 않는다.
- 그림만으로 충분한 장면은 영상 생성 없이 정지 그림 + 느린 줌으로 처리한다.

## 3. 쇼츠 (데일리 하루 2편)
- 새 그림·영상을 만들지 않는다. 전부 라이브러리에서 고른다.
- 최근 7일 안에 쓴 클립은 피하고, 오래 안 쓴 클립부터 고른다.
- CLIPS.json `_note` 의 "쓰지 않는 클립"(예: libv_quill, libv_candle_diary)은 고르지 않는다.
- 같은 장면이 질리지 않게 하는 보충은 라이브러리 확장(5장)으로만 한다.

## 4. 롱폼 (주 4편)
- 편당 새로 만드는 것: 그림 약 15장, 영상 8개 이하. 그 편의 인물·사건·훅 장면에만 쓴다.
- 여운 장면·장 전환·분위기 장면은 라이브러리(lib_shot)에서 가져온다.
- 영상 8개를 넘겨야 하면 이유를 기획 단계에서 대표에게 먼저 알린다.
- 편 기획 때 라이브러리에 없는 범용 주제(예: 새 감정·계절·장소)가 필요하면, 그 편 전용이 아니라 범용 장면으로 만들어 추가한다.

## 5. 라이브러리 확장
- 목표: 범용 장면 약 80개(11/5 기준 기존 25 + 범용 24 생성 중).
- 확장은 기획안의 다음 편 주제 목록에서 장면이 비어 있는 주제부터 채운다.
- 만드는 기준: 특정 편 이야기에 묶이지 않을 것, 얼굴 클로즈업 금지(황제는 뒷모습·실루엣만), 주제를 화면 가로 가운데 두어 세로로 잘라도 쓰게(cx 0.5).
- 생성 묶음은 실행 1회 상한(SIDE_GEN_MAX_USD, 기본 3달러) 안에서 12장면 단위로 나눠 push 한다.
- 생성이 끝나면 클립을 확인하고, 쓸 만한 것만 CLIPS.json 에 이름·cx·장면 설명·쓰임새(use)를 추가한다. 못 쓰는 것은 `_note` 의 쓰지 않는 클립에 적는다.

## 6. 예상 비용 (실청구 기준, 저장소 기록값의 약 1.9배로 환산한 추정)
- 라이브러리 구축: 1회 약 16달러
- 롱폼: 편당 약 2~4달러, 월 약 35~70달러
- 데일리 쇼츠: 편당 약 0달러, 월 약 2~5달러(보충분)
- 프로젝트별 API 키를 나누면 실제 청구액으로 이 표를 다시 맞춘다.
