## ★ 제목 규칙 (2026-11-07 11:35 대표 지시로 교체 — 11/6 '~한 사람에게' 고정을 대신한다. 롱폼 썸네일 말투와 맞춤)
- 숫자 + 이유/방법 양식을 섞어 쓴다: "<상황> N가지 이유" / "<상황> N가지 방법" (N = 3·5·7 등). 숫자 없는 "~하는 이유", "~하는 방법"도 가끔 섞는다
  예) 사람에게 지치는 3가지 이유 / 무례한 사람을 대하는 5가지 방법 / 아무도 알아주지 않아도 버티는 7가지 방법 / 누가 나를 싫어해도 괜찮은 이유
- 숫자는 반드시 영상 안 실제 항목 수와 같게: "3가지 이유"면 대본에 이유 3개(화면에 I·II·III), "5가지 방법"이면 방법 5개. 맞출 수 없으면 숫자 없는 양식으로
- 같은 날 두 편은 서로 다른 양식(하나는 이유, 하나는 방법)으로. 소개 쇼츠도 같은 양식 + 필요하면 "| <황제 이야기 한 토막>" (예: 아무도 알아주지 않아도 버티는 방법 | 황후의 옷까지 판 황제)
- 이미 올린 편 제목은 바꾸지 않는다
- 해시태그(#shorts, #명상록 등)는 제목에 절대 넣지 않는다. 해시태그는 설명란 끝에만. "| 로마 황제의 일기" 같은 꼬리도 붙이지 않는다(소개 쇼츠의 "| <황제 이야기 한 토막>"만 예외)
- 40자 이내(보통 20자 안팎). 유튜브·인스타·틱톡·ed_posts.title 모두 같은 글자 그대로
- 첫 화면 큰 흰 훅 2줄 = 이 제목
- 기계 검사: yt_up.sh 가 제목에 '#' 이 있거나 40자를 넘으면 업로드하지 않고 멈춘다

## 양식·음성·믹스 (2026-11-04 대표 확정)
- 양식은 A 하나로 고정. "A·B·C 돌리기" = 장면 묶음(그림 세트)을 돌리는 것이지 양식을 바꾸는 게 아님. B(밝은 대리석)·C(레터박스)는 쓰지 않음
- 장면은 어두운 명암 그림만 (밝은 그림은 가운데 자막이 안 읽힘)
- 음성: 문장 묶음마다 따로 녹음해 잘라 붙이지 않음(voice_v2.py). tighten.py(쉼 잘라 붙이기) 쓰지 않음
- 명상록 인용은 황제 목소리 명일 tc_62d66c2d1523be99355fda02 (tonedown, tempo 0.9, 롱폼과 같은 막사 울림 아주 약간), 나머지는 해설 건석
- 믹스: 조각마다 -16 LUFS, 한 번에 거는 loudnorm 대신 +2.5dB + alimiter. 내보내기 전에 voice_qa.py 통과 필수
- 마지막 화면: 롱폼 인트로와 같은 금색 디자인(금빛 주화·THE EMPEROR'S DIARY·금색 테두리 버튼)
- 길이 실험: 35·45·55초 전후를 시간대마다 날마다 돌림 (DAILY_RUN.md)
- 매일 제작은 예약 작업이 DAILY_RUN.md 대로 04:41에 시작

- 릴스와 같은 주제여도 각도는 다르게: 릴스 = 역설 한 줄 훅, 카드 = "○○할 때, 로마 황제가 일기에 쓴 N줄" 목록형(저장용)
- 구성 7장(1080×1350): 표지(금색 출처 줄 + 큰 제목 3줄 + 넘겨서 보세요) → I~V 항목(상황 제목 · 금색 세로선 인용 · 『명상록』 권 절 · 풀이 2줄) → 오늘 밤 할 일 + 슬로건
- 만들기: cards/<id>.json 작성 → python3 make_card.py cards/<id>.json docs/emperor/card → 한 장 모아 눈으로 점검 → push
- 게시: ed_posts 에 kind='carousel', images=[docs/emperor/card/<id>_01.jpg …], to_ig=true, to_th=false, video_path='' 로 넣으면 ed-publish 가 캐러셀로 올림(댓글은 ig_comment). 틱톡은 Chrome 스튜디오 사진 업로드(tt_text)
- 인용은 권·절을 반드시 확인한 것만. 현대 장면(ed03_subway) 쓰지 않음

## 쇼츠 '관련 동영상'(본편 연결) — Chrome 스튜디오 절차 (2026-11-07 확인)
- 같은 구글 계정에 밸류노트·황제의 일기 채널이 같이 있다. 스튜디오가 밸류노트로 로그인돼 있으면 영상 편집 화면은 열리지만 '관련 동영상' 선택 창 목록이 비어 있고 검색도 0건이 된다(원인: 요청 신원이 밸류노트).
- 그래서 먼저 오른쪽 위 프로필 → 계정 전환 → '황제의 일기'로 바꾼 뒤 studio.youtube.com/video/<쇼츠 id>/edit → 오른쪽 '관련 동영상' 연필 → 본편 선택 → 저장 → 새로고침해 이름이 남았는지 확인.
- 끝나면 계정을 굳이 되돌리지 않는다(밸류노트 작업은 시작할 때 자기 채널로 전환하는 같은 규칙을 따른다).
