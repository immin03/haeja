## 용어는 첫 장에서 먼저 풀어 준다 (2026-10-25 운영자 지적, 모든 개념형 카드에 적용)
운영자: "PBR이 뭔지 모르니까 먼저 알려 주고 그다음에 시작을 해야지." K261025a가 PBR·ROE 설명 없이 회사 숫자부터 보여 줬다.
- PER·PBR·ROE·배당성향 같은 용어가 나오는 카드는 **1장을 그 용어 설명으로** 시작한다: 한 줄 정의(일상 말로) + 큰 예시 한 줄(예: 'PBR 0.5배 = 장부상 1만 원어치를 5,000원에 사는 셈') + 공식은 작은 글씨로.
- 2장 이후에 새로 나오는 용어(예: PBR 편의 ROE)도 1장에서 같이 풀어 둔다. 설명 없이 처음 나오는 용어가 한 개라도 있으면 기획 검수에서 탈락.

## 장 수보다 '읽자마자 이해'가 먼저 (2026-10-25 운영자, K261025b 삭제 후 K261025c로 다시 만듦)
운영자: "카드뉴스가 몇 장 길어지더라도 읽었을 때 바로 이해될 수 있게 만드는 게 훨씬 중요해. 유튜브 롱폼처럼 쉬운 키워드로, 접근성 좋게." K261025b는 기준 4개를 한 장에 용어(PER·PBR·순이익)로 몰아넣어 처음 보는 사람이 이해하지 못했다.
- 위 '장 수 2~5장'보다 이 규칙이 우선한다. 개념이 여러 개면 6~10장도 괜찮다.
- 순서: 표지(질문형) → 거장이 가장 중요하게 본 것 한 장 → 기준 하나당 한 장 → 한 장으로 다시 보기 → 결과 명단 → 내 종목 체크.
- 기준은 용어가 아니라 **질문**으로 쓴다("PER 15배 이하" → "버는 돈에 비해 너무 비싸지 않나요?"). 생활 예시를 먼저 보여 주고(1억 원 가게가 1년에 1,000만 원 벌면 본전까지 10년) 그다음에 "이걸 PER이라고 부릅니다"로 용어를 붙인다. 공식은 작은 글씨로만.
- 명단 표의 칸 이름도 쉬운 말로("본전까지 약 6년", "재산의 몇 배").
- 기준 장 아래에는 text의 result(예: ["141곳", "85곳 통과"])로 걸러지는 과정을 보여 준다.

## 기획 관문 (릴스와 같다: 만든 뒤가 아니라 기획 단계에서 거른다)
1. 기획안(장별 한 줄 + 쓸 숫자와 출처 + 기준일)을 먼저 쓰고, 별도 검수자 에이전트가 처음 보는 인스타 사용자 입장에서 6개 항목(첫 장 클릭 욕구, 이해 쉬움, 정보 가치, 내 돈에 쓰는 법, 신뢰성, 홍보 자연스러움)을 채점한다. 평균 8.5 이상, 7점 이하 항목 없음이어야 만든다. 탈락하면 다른 소재로 다시 기획한다.
   - **통과할 때까지 멈추지 않는다 (2026-10-23 운영자):** "기획에서 통과가 안 되면 바로 다른 기획을 넣어야지. 워렌 버핏은 어떤 기준으로 투자할까? 정도의 아주 마이너하고 쉬운 내용도 괜찮아. 기획이 통과 안 됐다고 멈추지는 마." 기획 수 상한 없음. 탈락하면 필수 수정을 반영해 같은 검수자에게 다시 채점받거나(SendMessage), 더 쉬운 소재로 바꿔 계속한다. 자리를 비워 두고 끝내지 않는다.
   - 검수에서 자주 걸린 것(K261024a, 9번째 기획에서 통과): 기간 혼합(4년·5년)을 표기 없이 섞기, 앱에서 바로 못 보는 숫자로만 된 실천법, 확인 못 한 사실(증자 이유 등), '대형주'처럼 부정확한 범위(156곳 중 53곳은 코스닥 → '국내 상장사'), 고른 기준 없는 명단, 표지 큰 줄의 전문 용어, 밸류노트 기준을 거장의 기준처럼 쓰기. 통과에 도움 된 것: 아는 회사 이름, 유명 회사의 탈락 사례 한 개(예: SK하이닉스), 네이버 '기업실적분석' 표로 하는 O/X 체크.
2. 통과하면 필수 수정을 반영해 spec을 쓰고 렌더한 뒤, 모든 장을 열어 넘침·겹침·숫자 오타만 확인한다.

## 내용 규칙 (첫 기획 검수에서 나온 것 포함)
- **기준일은 하나로.** 한 편 안의 주가·적정 주가·점수는 같은 날 데이터(c/scores.json의 date와 screen 데이터)로 맞추고 모든 장 아래에 "○월 ○일 종가 기준"을 쓴다.
- **명단은 전부 보여 주거나 고른 기준을 밝힌다.** 조건을 통과한 회사가 6곳이면 6곳 전부. "몇 곳 중 몇 곳"을 쓴다.
- **출처를 구분한다.** 거장이 실제로 한 말·쓴 기준(원문 확인, 예: 버크셔 연차보고서 인수 기준)과 밸류노트가 덧붙인 기준을 장 안에서 구분해 쓴다. 지어낸 "버핏의 기준 숫자"를 쓰지 않는다.
- 회사 카드 한 장에 숫자는 3~4개까지. "40% 저평가"보다 "적정 주가보다 40% 낮게 계산됨"처럼 매수 권유로 읽히지 않게, 명단 장에는 "종목 추천이 아닙니다"를 넣는다.
- 경험칙("3배 넘게 차이 나면")은 경험칙이라고 밝히고, 반대 경우(구조적 호황 등)를 한 줄 넣는다.
- 밸류노트 로고는 og.png 워드마크를 그대로 잘라 쓴다(cardnews.mjs가 자동). 인물 사진은 위 '인물 사진' 규칙을 따른다.
- 마지막 장만 밸류노트 한 줄 + 프로필 링크 안내. 고지문은 마지막 장 아래 작게. 무료/유료라는 말을 쓰지 않는다. 인물은 "워렌 버핏", "벤저민 그레이엄"처럼 성까지.
- 캡션은 카드 내용을 문장으로 풀어 5~7문단, 끝은 프로필 링크 안내. 해시태그 5~6개.

## 만들고 올리기
1. `scripts/cards/specs/K<yymmdd><a|b>.json` 작성. 위 '포맷을 돌려 가며 쓴다'에서 직전 2편과 다른 포맷을 고른다(예: K261023a·b = 한 장 타일, K261024a = 사진 표지 → 기준 → 명단 표 → 체크). 장 종류는 cardnews.mjs 맨 위 설명.
2. `node scripts/cards/cardnews.mjs scripts/cards/specs/<id>.json` → `social/cards/<id>/NN.jpg`, `post.json`. 모든 장을 Read로 열어 본다.
3. 커밋·푸시 → Vercel 배포 후 `https://www.valuenote.co.kr/social/cards/<id>/01.jpg`가 200인지 확인.
4. Supabase `social_posts`에 행을 넣는다 (kind 'carousel', approved true, images = post.json의 경로). 게시는 social-publish(5분마다)가 한다.
