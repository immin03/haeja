# What Korea Says 리브랜딩 — 진행자 까치(Kachi) 미니어처 채널 (2026-10-27)

## 결론
- 채널 이름 **What Korea Says**와 핸들 **@WhatKoreaSaysTV**는 그대로 둔다. 구독자가 0명이라 바꾸는 비용은 없지만, 까치는 "한국에 반가운 소식을 전하는 새"라서 'Korea Says'의 화자로 자연스럽게 들어맞는다. 검색어 'Korea'도 이름에 남는다.
- 바뀌는 것은 정체성이다. 이전 콘셉트는 "한국 반응 모음"이었고, 새 콘셉트는 "까치가 미니어처 세계에서 들려주는 한국의 이상하고 재밌는 실화"다.
- 시청자층은 13~45세 해외 시청자다. 가족이 같이 봐도 되는 수준으로 만들되 **'아동용 아님'**으로 설정한다(아동용이면 맞춤 광고와 댓글이 막힌다).
