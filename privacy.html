2. 개인정보의 이용 목적

  • 회원 식별, 로그인, 계정 관리
  • 포트폴리오 평가, 기업 점수 계산, 알림 발송 등 서비스 기능 제공
  • 투자 성향에 맞춘 정렬·제안 제공
  • 방문·이용 통계 분석을 통한 서비스 개선
  • 문의 응대 및 서비스 관련 공지
  • 정리본을 신청한 분께 정리본 제공, 새 정리본·칼럼 안내 메일 발송 (메일 하단 링크나 개인정보 보호책임자 이메일로 언제든 수신을 거부할 수 있습니다)

3. 보유 및 이용 기간

  • 회원 정보와 이용자가 입력한 정보: 회원 탈퇴 시 지체 없이 파기
  • 정리본 신청 이메일: 수신 거부 또는 삭제 요청 시 지체 없이 파기, 그렇지 않으면 마지막 신청일로부터 2년 보관 후 파기
  • 방문 기록: 수집일로부터 1년 보관 후 파기 (회원 탈퇴 시 해당 회원의 기록은 즉시 파기)
  • 관련 법령에 따라 보존이 필요한 경우 해당 기간 동안 보관

4. 개인정보의 제3자 제공

서비스는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 법령에 따라 요구되는 경우는 예외로 합니다.

6. 개인정보의 파기 절차 및 방법

보유 기간이 지나거나 처리 목적이 달성된 개인정보는 지체 없이 파기합니다. 전자적 파일은 복구할 수 없는 방법으로 삭제합니다.

7. 이용자의 권리와 행사 방법

  • 이용자는 언제든지 자신의 개인정보를 열람·정정·삭제하거나 처리 정지를 요구할 수 있습니다.
  • 이름·투자 성향은 계정 설정에서 직접 수정할 수 있습니다.
  • 계정 설정 → 회원 탈퇴를 누르면 계정과 입력한 모든 정보가 즉시 삭제됩니다.
  • 그 밖의 요청은 아래 개인정보 보호책임자에게 이메일로 할 수 있으며, 지체 없이 조치합니다.

8. 브라우저 저장소 사용

서비스는 로그인 유지, 마지막으로 본 화면, 무작위 방문자 식별번호를 이용자 브라우저의 저장소(localStorage)에 보관합니다. 이용자는 브라우저 설정에서 사이트 데이터를 삭제해 이를 지울 수 있으며, 이 경우 다시 로그인해야 합니다.

12. YouTube API 서비스 이용 (YouTube API Services)

밸류노트는 운영자가 소유한 밸류노트 유튜브 채널(@valuenote_korea)에 영상을 올리고, 그 채널의 영상 통계와 댓글을 관리하기 위해 YouTube API 서비스를 사용합니다. 이 기능은 운영자 계정에만 연결되며, 일반 이용자의 유튜브 계정에는 접근하지 않습니다.

  • YouTube API 서비스를 이용하는 부분에는 YouTube 서비스 약관이 함께 적용됩니다.
  • YouTube API 서비스를 통해 처리되는 정보에는 Google 개인정보처리방침이 함께 적용됩니다.
  • 사용하는 정보: 밸류노트 채널 식별자·채널 이름, 업로드한 영상의 제목·설명·조회수 등 통계, 해당 채널 영상에 달린 공개 댓글. 인증 토큰은 암호화된 서버 데이터베이스에만 보관하며 외부에 제공하지 않습니다.
  • 접근 권한 철회: Google 보안 설정의 서드파티 액세스 페이지에서 언제든 밸류노트의 접근 권한을 해제할 수 있습니다. 권한이 해제되면 보관 중인 인증 토큰은 사용할 수 없게 되며, 요청 시 7일 안에 삭제합니다.
  • YouTube API 서비스로 받은 통계 정보는 채널 운영 분석 목적으로만 쓰고, 30일이 지나면 갱신하거나 삭제합니다.
